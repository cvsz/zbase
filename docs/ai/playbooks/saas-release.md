# SaaS Release

Record version, commit SHA, artifact identity, target environment, migration state, feature flags, integrations, rollback target and release owner.

Verify login/session/revocation, role/object authorization, tenant-scoped DB/cache/jobs/files/audit data, billing signatures/idempotency/entitlements, migration rehearsal, backup/restore, queues/workers, provider outage behavior, deployment smoke tests and observability.

Do not perform a production release without explicit authorization.
