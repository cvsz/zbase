# Incident Response

Prioritize human safety, data/credential protection, containment, evidence preservation, safe recovery, root cause and corrective action.

Record start time, detection source, affected systems, symptoms, last known good version, recent changes and user/data impact. Preserve relevant logs, metrics, traces, deployment metadata, commit SHA, image digest, events, audit logs and database state before destructive actions.

Use the least destructive containment. After recovery verify service health, authn/authz, data integrity, critical workflows, monitoring and alerts.

Separate trigger, root cause, contributing factors, detection gap, containment gap and recovery gap.
