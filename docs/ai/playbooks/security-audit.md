# Security Audit

Map users, roles, tenants, assets, trust boundaries, public/admin/internal APIs, data stores, external providers, CI identities and infrastructure control planes.

Review authentication, authorization, tenant isolation, token/session lifecycle, validation, injection, XSS/CSRF/SSRF, path traversal, file upload, webhooks, secrets, sensitive logging, dependencies, supply chain, CI permissions, containers, IAM/RBAC, network exposure, rate limiting and auditability.

For each finding record ID, severity, component, evidence, precondition, impact, root cause, remediation, validation and residual risk.

Never reproduce discovered secrets or perform destructive exploitation against production.
