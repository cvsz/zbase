# Reusable Testing Prompt

Design validation proportionate to risk: unit, integration, E2E, auth/authz, tenant isolation, migration, failure-mode, resilience, load/stress/soak, backup/restore and rollback as applicable. Tests should validate behavior. Record command, environment, result and limitations. Classify unexecuted or incomplete tests using the canonical evidence-state decision rule in `../../../ZEAZ-INTRODUCTION.md`: use `BLOCKED` when a concrete prerequisite prevents verification, otherwise `UNVERIFIED` when evidence has simply not been obtained.
